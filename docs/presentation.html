2 minutes · problem

A PDF is not an eInvoice.

  • UAE finance teams are turning moving FTA and MoF dates into a readiness plan. One model checking itself will not catch its own miss.
  • The MoF July 2026 appointment date moved. On 7 November 2026 the larger cohort’s 30 October appointment date is already past.
  • AED 375,000 is a corporate-tax band. It does not set the eInvoicing phase. AED 50 million does, and the equal case is still unresolved.

3 minutes · architecture and tools

Two containers, one gateway, a person at the gate.

  • LangGraph is the planner. Extractor, classifier, and researcher operate. The validator is ordinary Python. The auditor does not see the classifier’s reasoning.
  • Pydantic holds the node outputs. SSE shows the handoff. Repair runs once, then the invoice is marked to verify.
  • Every model call is an OpenAI-compatible chat completion to the local OmniRoute gateway, primary gh/gpt-5.6-terra, one retry to gh/gpt-5.6-luna. A provider SDK is not in this repo.
  • Docker Compose is the run path. The tenant volume is encrypted. Backups sit on a second volume. RESIDENCY_VERIFIED is false, so only synthetic content can reach the model.

6 minutes · live demo

Desert Ledger, then a refusal.

  • Open the synthetic seat. Stated revenue is a customer assertion of AED 62,000,000. The TRN reads SYNTHETIC_TRN_NOT_VALID.
  • Load the batch. The validator rejects the missing buyer and the bad total, repairs the total once, and escalates.
  • Ask in Arabic why AED 375,000 does not schedule eInvoicing. Read the English passage from the corporate-tax guide.
  • The auditor disagrees on the free-zone line and the conflicting revenue. The July date loses to the 25 October 2026 FTA notice.
  • Approve a bounded pack. It is not a return. If the gateway is down, say the word replay before you play the labelled trace.

2 minutes · challenges

What the build actually hit.

  • MoF says “exceed” AED 50 million. FTA says “equal or exceed”. The desk refuses to pick a winner at equality.
  • The corporate-tax rates are on page 20 of the September 2023 PDF. The Arabic line is our translation, parked next to that English sentence.
  • A wrapped PDF broke the embedded JSON, so the fixture carries a base64 payload. Instruction-like text in an upload stays data.
  • LangGraph needed an explicit state or the batch disappeared between nodes. Token counts are real only when OmniRoute answers. The replay path records zeros and says so.
  • No accountant has scored the set. No saving is claimed. Residency of the upstream model is not verified.

2 minutes · vision

A jurisdiction pack a customer can supervise.

  • The same agent core can take a versioned pack for another country: frozen sources, deterministic checks, a human gate.
  • A DataRobot customer would run the containers, point storage and backups at the location their counsel requires, and turn on non-synthetic inference only after the provider’s processing location is checked.
  • Pilot it under supervision. Measure review time. Do not sell a saving that has not been measured, and do not promise an ASP connection this build does not have.

How the rubric is met

Problem, proof, and a visible catch.

  • Problem solving: dated deadlines, a boundary conflict, and a role for each risk.
  • Technical credibility: LangGraph, Pydantic, a deterministic validator, tenant isolation, and an audit row that survives a container restart.
  • Creativity: the audience sees the validator catch the classifier, then an Arabic answer with the English source beside it.
  • Strategic vision: containers, a residency gate, and a path to other jurisdiction packs without a fake compliance claim.
